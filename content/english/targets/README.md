# Long-term corpus targets

This directory encodes the master-plan scale targets as machine-readable data.

`long-term.json` is intentionally a readiness contract, not a publication claim.
`pnpm english-content:e11` measures current candidate/pilot coverage against the
locked goals. A low completion percentage is expected until E10 review quality stays
stable across multiple batches.

Do not satisfy these numbers by splitting topics artificially or by generating
large unreviewed corpora.
