# English Learning Content Attribution

The rich runtime now publishes three reviewed slices:

- E03 lexical slice: 10 lexemes + 10 normalized senses;
- E04 phrase/pattern slice: 250 records;
- E05 grammar slice: 12 topics + 36 examples + 24 exercises.

The E03 slice uses project-authored editorial normalization together with two publishable attributed sources:

- **Typing Game shared vocabulary** — CC-BY-SA-4.0. Existing attribution is retained in `shared/vocabulary/ATTRIBUTION.md`.
- **Open English WordNet 2025** — CC-BY-4.0, pinned to commit `dc343f2683279ecbb13fab4e2fd778d7b162d287`.

The runtime attribution manifest contains these sources because they are present in published-record provenance. Wiktionary-derived sources remain review-only and are not redistributed in the published E03 slice.

Other source policies remain unchanged:

- Tatoeba: retain sentence-level license/attribution if a reviewed translation slice is published.
- MultiWOZ: preserve MIT attribution if reviewed dialogue records are published.
- VerbNet: publication remains blocked until redistribution terms for the selected material are cleared.
- Cambridge English Profile: reference only; proprietary data is not copied.
- Project-original records require no external attribution entry.

The E12 maintenance audit derives attribution requirements from provenance actually present in runtime shards.
