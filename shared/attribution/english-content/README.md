# English Learning Content Attribution

The current rich runtime publishes the first reviewed **project-owned E05 vertical slice**: 12 grammar topics, 36 example sentences and 24 exercises. These 72 records use `project-original` provenance, so the English-content attribution runtime is intentionally empty for this release.

Third-party lexical, phrase, translation and dialogue sources remain candidate/draft inputs unless a later review decision explicitly publishes them. Source policy is defined in `content/english/sources/manifest.json`.

- Open English WordNet: attribution required when OEWN-derived records are published.
- Wiktionary-derived content: preserve applicable CC BY-SA/GFDL obligations when published.
- Tatoeba: retain sentence-level license/attribution; audio is separate.
- MultiWOZ: preserve MIT attribution for any published dialogue records.
- VerbNet: publication blocked until exact redistribution rights are verified.
- Cambridge English Profile: reference only; proprietary data is not copied.
- Project-original records: no external attribution runtime entry is required.

The E12 maintenance audit derives attribution requirements from provenance of the records actually present in published runtime shards, so adding a third-party source to the source catalog alone cannot create or suppress attribution obligations.
