# English Learning Content Attribution

The foundation release contains the project-owned 300-topic curriculum framework and empty runtime manifests; third-party lexical/sentence records have not yet been imported.

Source policy is defined in `content/english/sources/manifest.json`.

- Open English WordNet: attribution required.
- Wiktionary-derived content: preserve applicable CC BY-SA/GFDL obligations.
- Tatoeba: retain sentence-level license/attribution; audio is separate.
- VerbNet: publication blocked until exact redistribution rights are verified.
- Cambridge English Profile: reference only; proprietary data is not copied.
