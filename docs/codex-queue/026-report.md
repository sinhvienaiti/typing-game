## Kiểm 1 · rg -F cho từng tên

PATH không có `rg`; dùng binary có sẵn trong Cursor, không cài thêm và không dùng mạng. Mỗi tên hiện tại và mỗi alias ghi rõ được kiểm bằng **một tiến trình `rg -F` riêng**. Phạm vi là `src`, `tests`, `scripts` của đúng game; `*.ts`, `*.json`, `*.mjs`, `*.snap`.

Đếm cả chú thích, tên dài chứa tên ngắn và test ở kết quả thô bên dưới. Cột Chỗ trong bảng chính đã lọc chuỗi mã, gộp biến thể hoa/thường và phân biệt ngữ cảnh.

```sh
'/Applications/Cursor.app/Contents/Resources/app/node_modules/@vscode/ripgrep/bin/rg' -F -n --no-heading --color never --glob '*.ts' --glob '*.json' --glob '*.mjs' --glob '*.snap' -- '<tên>' games/<game>/src games/<game>/tests games/<game>/scripts
```

**Kết quả đã chạy: 163 lệnh; 163 có kết quả; 0 tên thiếu bằng chứng.** Mọi tên trong bảng chính và bảng cần xem đều có ít nhất một vị trí literal mã (không chỉ chú thích).

    if not game or not line.startswith('| ' + chr(96)):
        continue
    cells = [c.strip() for c in line.split('|')[1:-1]]
    aliases = cells[6].split('Bi\u1ebfn th\u1ec3: ', 1)
    names = [cells[1]] + (re.findall(chr(96) + '(.*?)' + chr(96), aliases[1]) if len(aliases) > 1 else [])
    for name in names:
        roots = [f'games/{game}/{p}' for p in ['src', 'tests', 'scripts']]
        args = [rg, '-F', '-n', '--no-heading', '--color', 'never']
        for glob in ['*.ts', '*.json', '*.mjs', '*.snap']:
            args += ['--glob', glob]
        result = subprocess.run(args + ['--', name] + roots, capture_output=True, text=True)
        commands += 1
        if result.returncode != 0 or not result.stdout:
            missing += 1
            print('MISSING:', game, name)
print(f'rg -F: commands={commands}, missing={missing}')
raise SystemExit(bool(missing))
