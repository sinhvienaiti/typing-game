## Status convention

Each design document should clearly distinguish:

- **Confirmed requirement** - explicitly requested/agreed and should not be changed silently.
- **Recommended design** - analysis/recommendation that can still be tuned with the user.
- **Future idea** - intentionally not part of the current implementation scope.

When a recommendation becomes confirmed, update both the design document and docs/PROJECT_CONTEXT.md.
